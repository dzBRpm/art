# 🧩 Артефакты — DayZ STALKERS ZONE PvEvP

Неофициальный информационный веб-проект, посвящённый артефактам проекта  
**DayZ STALKERS ZONE PvEvP**.

Сайт предоставляет визуальный каталог артефактов с иконками, описанием и
характеристиками, собранными на основе наблюдений сообщества и игрового опыта.

---

## ⚠️ Дисклеймер

Данный сайт **не является официальным ресурсом** проекта DayZ STALKERS ZONE PvEvP.

Вся информация представлена исключительно в ознакомительных целях и основана на:
- наблюдениях игроков;
- анализе игрового процесса;
- данных, собранных сообществом.

Администрация проекта DayZ STALKERS ZONE PvEvP не имеет отношения к данному сайту
и не участвует в его разработке.

---

## ✨ Возможности

- 📦 Каталог артефактов с иконками
- 🔍 Поиск по названию артефакта
- ⚙️ Поиск по характеристикам
- 🪟 Всплывающие модальные окна с описанием
- 📌 Закрепление модалок и свободное перетаскивание
- 🔄 Переключение между основными и дополнительными свойствами
- 🎨 Цветовые рамки по степени изученности
- 🌙 Тёмная тема интерфейса
- 📱 Частичная адаптация под мобильные устройства (в процессе)
